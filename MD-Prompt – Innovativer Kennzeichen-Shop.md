# Projekt: Innovativer Online-Shop für Kfz-Kennzeichen

## Ziel

Entwickle eine moderne, hochwertige und visuell außergewöhnliche Website für den Online-Verkauf von Kfz-Kennzeichen.

Die Website soll sich bewusst von klassischen Kennzeichen-Shops unterscheiden.

Es soll **nicht wie ein typischer Online-Shop** wirken.

Die Nutzer sollen das Gefühl bekommen, ihr eigenes Kennzeichen gerade digital zu konfigurieren und entstehen zu sehen.

Die Experience soll eher an einen modernen Produkt-Konfigurator erinnern:

- Apple
- Tesla
- moderner Fintech-Checkout
- hochwertige SaaS-Websites
- interaktive Produktkonfiguratoren

Das eigentliche Produkt – das Kennzeichen – steht visuell immer im Mittelpunkt.

---

# Kernidee

## „Du siehst dein Kennzeichen entstehen, bevor du es kaufst.“

Der Nutzer gibt seine gewünschte Kennzeichenkombination ein.

Beispiel:

`OL AB 123`

Während der Eingabe wird das Kennzeichen **live und realistisch dargestellt**.

Das Kennzeichen soll nicht nur ein statisches Bild sein.

Es soll sich wie ein echtes physisches Produkt anfühlen.

Dazu gehören:

- leichte 3D-Perspektive
- dezente Schatten
- Aluminium-/Metallwirkung
- reflektierende Oberfläche
- dezenter Lichtreflex
- realistische schwarze Prägeschrift
- Euro-Feld
- passende Proportionen

Die Animationen müssen hochwertig und ruhig wirken.

Keine übertriebenen Gaming-Animationen.

---

# Design-Richtung

Das Design soll:

- minimalistisch
- hochwertig
- schnell
- technisch
- vertrauenswürdig
- modern
- klar
- conversion-orientiert

wirken.

## Vermeiden

Keine klassische Shop-Optik mit:

- vielen kleinen Produktkarten
- riesigen Navigationsmenüs
- überladenen Bannern
- blinkenden Elementen
- aggressiven Rabatt-Badges
- generischen Stockfotos
- unnötigen Textwänden
- billig wirkenden Icons

Das Produkt selbst soll der visuelle Hero sein.

---

Grundsätzlich eine sehr reduzierte Farbwelt.

Empfehlung:

- Weiß / Off-White als Hauptfläche
- Dunkles Anthrazit für Texte
- Schwarz
- dezente Grautöne
- eine starke Marken-Akzentfarbe für CTAs

Der Kontrast muss hochwertig und modern wirken.

Nicht zu viele Farben verwenden.

Kurze Texte.

Keine unnötigen Marketingfloskeln.

Logo

# HERO-BEREICH

Der Hero ist das wichtigste Element der gesamten Website.

Großzügiger Fullscreen-Bereich.

## Headline

**Dein Kennzeichen.  
Deine Kombination.**

Alternative:

**Kennzeichen online prägen lassen.**

Darunter kurze Erklärung:

> Wunschkombination eingeben, Kennzeichen konfigurieren und direkt online bestellen.

---

# Live-Kennzeichen

Zentral im Hero befindet sich ein großes, realistisches Kennzeichen.

Beispiel:

`OL AB 123`

Unter oder direkt im Kennzeichen befindet sich die Eingabe.

Zum Beispiel:

[ OL ] [ AB ] [ 123 ]

oder ein einziges intelligentes Eingabefeld.

---

# Live-Eingabe-Animation

Während der Nutzer schreibt, soll sich die Beschriftung auf dem Kennzeichen unmittelbar verändern.

Nicht einfach Text ersetzen.

Die Zeichen dürfen eine sehr dezente „Prägeanimation“ bekommen.

Beispiel:

1. Nutzer tippt „O“
2. Buchstabe erscheint leicht aus der Tiefe
3. Schatten / Prägung wird sichtbar
4. nächster Buchstabe folgt

Animation ca. 150–250 ms.

Sehr dezent.

---

# 3D-Kennzeichen

Das Kennzeichen soll optional leicht auf Mausbewegungen reagieren.

Beispiel:

Maus links → Schild kippt minimal nach links.

Maus rechts → Schild kippt minimal nach rechts.

Maximal wenige Grad.

Zusätzlich bewegt sich der Lichtreflex sehr leicht.

Auf Mobile:

leichte Reaktion auf Scrollposition oder Gerätebewegung nur dann verwenden, wenn Performance und UX darunter nicht leiden.

---

# Kennzeichen-Reflexion

Über das Kennzeichen kann in großen Abständen ein sehr dezenter Lichtreflex laufen.

Keine permanente Animation.

Beispielsweise:

alle 8–15 Sekunden.

Die Reflexion soll die reflektierende Oberfläche des realen Kennzeichens andeuten.

---

# CTA

Direkt unter dem Konfigurator:

**Jetzt Kennzeichen erstellen**

oder

**Jetzt prägen lassen**

Der CTA soll dominant, aber hochwertig sein.

Daneben Preis:

**ab XX,XX €**

Preis darf später dynamisch eingebunden werden.

Keine erfundenen Preise fest programmieren.

---

# Scroll Storytelling

Nach dem Hero bleibt das Kennzeichen zunächst weiterhin sichtbar.

Beim Scrollen beginnt eine kleine Produkt-Story.

---

# SECTION 2 – Produktion

Headline:

## Heute bestellt. Schnell geprägt. Direkt verschickt.

Das Kennzeichen kann leicht zur Seite gleiten.

Daneben erscheinen nacheinander kurze Vorteile.

Beispiel:

### Hochwertige Prägung

Realistische Nahaufnahme bzw. Detailanimation des Kennzeichens.

### Reflektierende Oberfläche

Ein Lichtreflex läuft über das Schild.

### Versandbereit

Das Schild bewegt sich leicht Richtung Verpackung.

---

# SECTION 3 – Kennzeichen auswählen

Headline:

## Welches Kennzeichen brauchst du?

Keine gewöhnlichen Produktkarten.

Stattdessen befindet sich wieder ein großes Kennzeichen im Mittelpunkt.

Darunter Auswahlbuttons:

- Auto
- Motorrad
- E-Kennzeichen
- H-Kennzeichen
- Saisonkennzeichen

---

# Morphing-Animation

Wenn der Nutzer die Kennzeichenart wechselt, soll sich das Kennzeichen visuell verändern.

Beispiel:

### Auto → Motorrad

Das lange Kennzeichen verkleinert und verändert seine Form.

### Standard → E-Kennzeichen

Das „E“ erscheint animiert am Ende.

### Standard → H-Kennzeichen

Das „H“ wird ergänzt.

### Saisonkennzeichen

Der Saisonbereich erscheint auf der rechten Seite.

Die Veränderung soll weich animiert werden.

Keine Seitenneuladung.

---

# SECTION 4 – Kennzeichen-Scanner

Ein visuelles Feature, das den Konfigurator technisch und modern wirken lässt.

Headline:

## Dein Kennzeichen konfigurieren

Nutzer gibt beispielsweise ein:

`HH AB 1234`

Nach Eingabe läuft eine kleine Scanlinie über das Kennzeichen.

Anschließend erscheinen:

✓ Format erkannt  
✓ Kennzeichen erstellt  
✓ bereit zur Bestellung

Darunter Preis und CTA.

WICHTIG:

Keine Aussage zur tatsächlichen Verfügbarkeit eines Kennzeichens treffen, wenn keine entsprechende Zulassungsstellen-API vorhanden ist.

Keine Formulierungen wie:

„Kennzeichen verfügbar“

wenn dies technisch nicht geprüft wird.

Stattdessen:

- Format erkannt
- Kombination übernommen
- Kennzeichen konfiguriert

---

# SECTION 5 – So funktioniert es

Extrem simpel.

Drei Schritte.

## 1. Kennzeichen eingeben

Wunschkombination konfigurieren.

## 2. Sicher bezahlen

Zahlung direkt online.

Stripe integrieren.

Mögliche Zahlungsmethoden abhängig von der Stripe-Konfiguration.

## 3. Wir prägen und versenden

Produktion und Versand.

Visuell können die Schritte mit einer kleinen horizontalen Animation verbunden werden.

---

Versand

# SECTION 7 – Trust

- Schneller Versand
- hochwertige Prägung

- transparente Preise

Nur Aussagen verwenden, die tatsächlich stimmen.

Mögliche Fragen:

- Welche Größen gibt es?

- Kann ich Motorradkennzeichen bestellen?

Kein unnötig komplizierter Warenkorbprozess.

Idealerweise:

## One-Page-Checkout

Desktop:

### Linke Seite

Große Live-Vorschau des bestellten Kennzeichens.

Darunter:

- Kennzeichenart
- Größe
- Anzahl
- Preis

### Rechte Seite

- Kontakt
- Lieferadresse
- Versand
- Zahlung

# Animationen

Animationen sollen ein wesentlicher Bestandteil der Website sein.

Aber:

## Regel

**Animation unterstützt die Bedienung. Animation ersetzt keine Bedienung.**

---

# Erwünschte Animationen

- Fade-in
- Slide-up
- dezente Parallax-Effekte
- Kennzeichen-3D-Tilt
- Prägeanimation der Buchstaben
- Lichtreflex
- Morphing zwischen Kennzeichenformaten
- Scanlinie
- animierte Fortschrittsanzeige
- Smooth Scrolling
- Scroll Storytelling
- Hover-Reaktionen
- kleine Button-Microinteractions

---

# Vermeiden

Keine:

- wilden Partikelanimationen
- extremen Zooms
- langen Introanimationen
- unnötigen Loader
- Animationen, die den Kauf verzögern
- dauerhaft bewegten Hintergründe
- Performance-Killer
- Audioeffekte

---

# Performance

Die Seite muss trotz Animationen extrem schnell bleiben.

Ziel:

- gute Core Web Vitals
- keine unnötig großen Libraries
- Lazy Loading
- moderne Bildformate
- SVG wenn möglich
- reduzierte JavaScript-Menge
- GPU-freundliche Animationen

Animation hauptsächlich über:

- transform
- opacity

realisieren.

---

# Accessibility

`prefers-reduced-motion` berücksichtigen.

Wenn Nutzer reduzierte Animationen eingestellt haben:

- keine großen Bewegungen
- keine Parallax-Effekte
- keine unnötigen 3D-Effekte

Die Website muss weiterhin vollständig funktionieren.

# Conversion-Grundsatz

Der Nutzer soll spätestens wenige Sekunden nach Seitenaufruf verstehen:

1. Hier kann ich mein Kennzeichen erstellen.
2. Ich kann meine Kombination direkt eingeben.
3. Ich sehe sofort, wie es aussieht.
4. Ich sehe den Preis.
5. Ich kann direkt bestellen.

Alles, was davon ablenkt, reduzieren.

---

# Wichtigster USP der Website

Die Seite verkauft nicht einfach nur zwei Stück Aluminium.

Sie verkauft die Experience:

## „Erstelle dein Kennzeichen live.“

Das Kennzeichen muss deshalb auf nahezu jeder wichtigen Seite bzw. jedem wichtigen Schritt sichtbar sein.

# Gesamtwirkung

Die Website soll beim ersten Besuch den Eindruck erzeugen:

> „So modern habe ich noch nie ein Kennzeichen bestellt.“

Sie darf technisch und innovativ wirken, soll aber trotzdem extrem einfach bedienbar bleiben.

Prioritäten:

1. einfache Bedienung
2. Kennzeichen-Konfigurator

4. Geschwindigkeit
5. hochwertige Animation

7. mobile UX
